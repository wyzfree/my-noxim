# 毕业论文执行清单（中文版）

适用课题：基于 SystemC 对 Noxim 进行并行优化（芯片内 + 多芯片），并验证其在现代大规模 NoC 模拟中的有效性。

## 一、最低可毕业必做项（必须完成）

## 1. 问题定义与基线建立
- [ ] 明确原始 Noxim 的执行模型（单线程/单进程特性）与限制。
- [ ] 明确瓶颈来源（如事件调度开销、跨芯片模拟能力不足等）。
- [ ] 固定一个“原版基线 commit”用于对照，避免对比不公平。

## 2. 多芯片并行支持（你已完成大半）
- [x] 基于 FileIO 的多进程多芯片链路可运行。
- [x] 跨芯片通信一致性校验可通过（TX/RX 计数一致）。
- [ ] 将设计细节写清：为什么用 FileIO、同步策略、顺序保证、局限性。

## 3. 芯片内并行优化（题目匹配关键）
- [ ] 至少实现一项“芯片内部”优化（不能只做芯片间拆分）。
- [ ] 该优化必须可开关（A/B 对照）。
- [ ] 对照验证：开关前后功能正确性一致。

## 4. 定量实验与可扩展性证明
- [ ] 报告总仿真时间、加速比、并行效率。
- [ ] 芯片数扩展实验（如 1/2/4/8/16/32）。
- [ ] 单芯片规模扩展实验（如 4x4/8x8/16x16 等）。
- [ ] 至少包含：合成流量 + 任务流量（MNIST-SNN）两类工作负载。

## 5. 正确性与可复现性
- [ ] 通信层正确性：期望计数与实测计数一致。
- [ ] 任务层正确性：输出预测与标签对比，给出准确率。
- [ ] 一键脚本复现实验（命令、参数、配置、随机种子可追溯）。

## 6. 论文材料完整性
- [x] 方法描述（中英文）已初稿。

- [x] 实验参数模板已建立。

## 二、建议实验矩阵（建议完整跑一轮）

## A. 模拟器性能实验（核心）
- [ ] 固定总规模，变化芯片数量（看并行扩展收益）。
- [ ] 固定芯片数量，变化每芯片规模（看单芯片负载变化）。
- [ ] 基线版 vs 优化版对比（同配置、同 seed）。

## B. 通信一致性实验（稳定性）
- [ ] 每组实验都记录：
  - 发送包数（TX packets）
  - 接收 flit 数（RX flits）
  - 结束时 pending 队列长度
- [ ] 验证长时运行无丢记录问题。

## C. 任务级实验（MNIST-SNN）
- [ ] 多个 `start_idx` 窗口重复测试（避免只测一段数据）。
- [ ] 报告准确率均值/方差。
- [ ] 同时报告任务下的 throughput、delay、energy（若可得）。
